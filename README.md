# 🌿 نظام إدارة عيادة الشفاء الطبية الذكية
### Smart Clinic Management System (Care & Billing System)

نظام إلكتروني متكامل وشامل لإدارة العيادات والمراكز الصحية، تم تصميمه وتطويره وفق أحدث المعايير البرمجية لتنظيم العمليات الطبية والإدارية والمالية بدقة وسلاسة.

---

## 🌟 الميزات الرئيسية للنظام

1. **📊 لوحة التحكم والإحصائيات الحية (Dashboard)**:
   - مؤشرات بيانية لحظية لأعداد المرضى، مواعيد اليوم، الأطباء المتاحين، ومخزون الأدوية.
   - إحصائيات مالية دقيقة لإجمالي الإيرادات والتحصيل بالجنيه السوداني (**ج.س**).
   - تنبيهات فورية لنقص الأدوية والمواعيد الأخيرة.

2. **👥 إدارة المرضى والسجل الطبي الموحد (Patients & EMR)**:
   - تسجيل المرضى مع توليد أرقام تعريفية موحدة (`Patient ID`).
   - حفظ الملف الطبي، فصيلة الدم، التاريخ المرضي، والملاحظات السريرية.
   - محرك بحث وفلترة سريعة بالاسم ورقم الهاتف.

3. **📅 جدول المواعيد والحجوزات (Appointments)**:
   - جدولة دقيقة للمواعيد وتوزيع المرضى على الأطباء المتاحين.
   - تفادي التعارض الزمني في جداول الكشف.
   - فلترة المواعيد حسب التاريخ، الطبيب، والحالة (*مؤكد / في الانتظار / مكتمل / ملغي*).

4. **👨‍⚕️ إدارة الكادر الطبي والأطباء (Medical Staff)**:
   - ملفات تعريفية للأطباء مع التخصصات، أرقام العيادات، وساعات الدوام الأسبوعية.
   - مؤشرات الحالة اللحظية (*متاح اليوم / في غرفة الكشف / في إجازة*).

5. **💊 إدارة الصيدلية ومخزون الأدوية (Pharmacy & Inventory)**:
   - قاعدة بيانات الأدوية مع التصنيفات، الأسعار بالجنيه السوداني، وتواريخ الصلاحية.
   - نظام تنبيهات ذكي للأصناف التي أوشكت على النفاد.

6. **💳 نظام الفواتير والمدفوعات المتكامل (Billing & Invoices)**:
   - إصدار فواتير ذكية مع بنود خدمات وأدوية ديناميكية وحسابات فورية للخصم والضريبة.
   - دعم خيارات الدفع المتعددة: *نقدي (كاش)، بطاقة مصرفية، تحويل بنكي (تطبيق بنكك / فوري)، تأمين صحي*.
   - **سند وفاتورة رسمية قابلة للطباعة (`Printable Invoice`)** مجهزة للطباعة المباشرة على مقاس A4 بضغطة زر واحدة.

## 🚀 التقنيات المستخدمة
- **HTML5**: هيكلة دلالية متوافقة مع معايير الويب ومعايير الوصول.
- **CSS3 / Modern Vanilla CSS**: نظام تصميم مخصص بألوان هادئة ومريحة للمجال الطبي (Sky Blue & Coral Pink) وتصميم متجاوب بالكامل.
- **JavaScript (ES6+)**: إدارة الحالة ومعالجة العمليات الحسابية والفلترة وحفظ البيانات محلياً عبر `LocalStorage`.
- **Font Awesome & Google Cairo Font**: خطوط وتدرجات وأيقونات عصرية.

## 💻 طريقة التشغيل محلياً

1. استنساخ المستودع (Clone):
   ```bash
   git clone https://github.com/MutazHaroun/sheifacare.git
   ```
2. فتح المجلد وتشغيل خادم محلي:
   ```bash
   # باستخدام Python
   python -m http.server 3000
   ```
3. فتح المتصفح على:
   `http://localhost:3000/`
